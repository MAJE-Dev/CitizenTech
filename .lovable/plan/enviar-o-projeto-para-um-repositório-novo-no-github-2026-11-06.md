# Enviar o projeto para um repositório novo no GitHub

Você faz isso pelo Lovable. Não precisa mudar nenhum código.

## Passos (no computador)
1. Clique no nome do projeto, no canto superior esquerdo, e depois em **Settings**. Lá, abra **Git**. Outro caminho: botão **+** no chat → Project → GitHub.
2. Clique em **Connect** e autorize sua conta do GitHub. Escolha a conta ou a organização **MAJE-Dev**. Se ela não aparecer, autorize o acesso do Lovable a ela no GitHub.
3. O Lovable cria um repositório novo e privado, e envia todo o código para ele.
4. No GitHub, abra o repositório → Settings → deixe ele **Public**, ou adicione o professor em Collaborators.
5. A partir daí, toda mudança feita no Lovable vai para o GitHub sozinha.

## Observações
- O repositório MAJE-Dev/CitizenTech que já existe não pode ser usado. Se quiser esse nome, apague ou renomeie o antigo antes de conectar.
- No celular: modo Chat → botão **+** → Project → GitHub.
- Este projeto é um site em React, não Expo. Confirme se isso atende à regra do trabalho.
